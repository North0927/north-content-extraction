# 依赖、数据与验证边界

| 能力 | 依赖 |
| --- | --- |
| 文字分析 | 用户选择的 AI 模型及文件读写 |
| Markdown／HTML | 宿主生成或可选 Node.js 渲染器 |
| 策略与空间 | Python 3.10+ 标准库，仅计划与测量 |
| 多执行者 | 宿主真实接口及授权，不附送实现 |
| 媒体获取、转录、听辨、画面 | 外部工具分别验收，文字案例不覆盖 |

Windows 为业务首测，macOS 未实机验证，Linux 文档构建不等于业务实测。任务单校验针对 Windows 路径。

本项目不提供共享密钥、后台采集或自动发布。数据去向取决于使用者选择的 AI 宿主与工具。
