# 故障排查

| 现象 | 恢复操作 | 成功判断 |
| --- | --- | --- |
| 只读标题就写全文 | 提供实际正文，旧结果标部分 | 结论对应段落 |
| 看不到目录 | 检查宿主权限或提供可读附件 | 能回读原文 |
| 无多执行者接口 | 排队，或用户明确当前会话直做 | 记录真实方式 |
| 缺转录、听觉或视觉 | 保留证据和缺项再决定服务 | 不混称全面完成 |
| Python 不存在 | 用已安装的 py -3 或文字路径 | --help 可运行或明确不用脚本 |
| 模式变简略 | 查时长、整夹、峰值及完整性 | 原因明确，不删素材绕门槛 |
| HTML 已存在 | 使用新版本文件名 | 原文件未覆盖 |
| 文档资源失败 | 核对项目站 base 与路径 | 页面图片搜索可用 |

反馈含版本、系统、宿主、步骤及脱敏错误，不提供密钥或私人素材。
