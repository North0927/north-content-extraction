# 升级与回退

发行 0.1.0 对应业务协议 2.3.2 与源修订，分别登记，不只比一个数字。

## 首次安装

首个公开版无旧公开版迁移。已有同名内部版时保留原目录及配置，在新测试目录解压，避免覆盖在用版。

## 后续升级

1. 阅读版本发布（Releases）的变更与兼容性。
2. 保存旧版、依赖和配置，素材与报告单独留存。
3. 下载新包，核对哈希，在新目录解压。
4. 合并必要配置，不覆盖未知字段与凭据。
5. 用示例试跑，核对报告、来源和缺项。
6. 通过后切换入口，记录旧入口与恢复位置。

## 回退

停止新任务，把入口指回旧目录和配置，以同一材料复核。保留失败报告和原始素材。

同版本不静默换包。网页可恢复旧构建，已下载副本不能据此全部撤回。
